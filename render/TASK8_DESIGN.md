## Per-draw constants correctness under one command buffer
BDA loads happen at EXECUTION time ⇒ you cannot reuse one buffer slice and rewrite it
between draws. Use a per-frame ARENA buffer (host-visible, SHADER_DEVICE_ADDRESS usage):
snapshot VS consts / PS consts / SharedConstants into fresh slices whenever their tracked
state is dirty at a draw, and vkCmdPushConstants the three slice addresses per batch.
(Boot frame = constants written once ⇒ 1 slice each + per-batch SharedConstants slices
differing only in texture index.)

## Vertex input (raw guest data — DELETE the CPU decode-to-NDC path)
Bind the guest VB region directly (copy the draw's vertex range into a per-frame VB like
today, but RAW bytes, stride 24). Attributes (locations from generated HLSL):
  loc0 POSITION0  VK_FORMAT_R32G32B32_SFLOAT offset 0  (float4 in shader; w defaults 1)

Index path: keep the existing tri-fan→tri-list index conversion exactly as is.

## Viewport / transform (replaces ALL hand math — VTE state from the ring)
Track TYPE0 writes to 0x210F XSCALE / 0x2110 XOFFSET / 0x2111 YSCALE / 0x2112 YOFFSET /
0x2113 ZSCALE / 0x2114 ZOFFSET / 0x2206 PA_CL_VTE_CNTL during the walk, with defaults
XSCALE=640 XOFFSET=640 YSCALE=-360 YOFFSET=360 ZSCALE=1 ZOFFSET=0, VTE_CNTL=0x43F
(measured from the root ring's init IB — these regs are set at GPU init, NOT per frame).
VS outputs D3D NDC; guest fb mapping is x' = ndc.x*640+640, y' = ndc.y*(-360)+360.
In Vulkan use dynamic viewport: VkViewport{x=XOFFSET-XSCALE, y=YOFFSET-YSCALE,
width=2*XSCALE, height=2*YSCALE... careful with sign: guest YSCALE=-360 flips Y; Vulkan
NDC Y is already down vs D3D up ⇒ net: try VkViewport{0, 0, 1280, 720} first (double
flip cancels), fall back to {0,720,1280,-720} if the image is vertically mirrored vs
ground truth. Depth range 0..1, depth test off. If VTE_CNTL bit8 (XY_FMT, pre-transformed
pixels) ever appears set, log it loudly (not expected in boot frames).
