Mushihimesama Futari Ver 1.5 -- futari_realcomp, native Steam Deck / Linux x86_64 build @VER@ (BETA 3, family-and-friends).
Not a release. Engine build id: @BUILD@

REQUIREMENTS
  Steam Deck (SteamOS 3.5 or newer) or any x86_64 Linux with glibc 2.36+, Vulkan 1.2 and a GPU driver (RADV on the Deck).

INSTALL
  1. Copy this whole folder somewhere on the Deck (the SD card is fine), e.g. /run/media/deck/1tb/Futari-Realcomp-Deck.
  2. In Desktop Mode, Steam > Add a Non-Steam Game > Browse > pick "futari-realcomp" in that folder.
     Properties: Compatibility = NONE (it is native), launch options empty.
  3. Switch to Gaming Mode and launch it. Desktop Mode runs with the GPU pinned to idle clocks and is NOT representative.

MODES
  Both Ver 1.5 modes: ARCADE (1.5 Original) and XBOX 360 MODE, picked at the in-game title select; switching modes
  from the top menu swaps live. Ver 1.01 and Black Label stay greyed (not included).

CONTROLS
  The Deck's controller works through Steam Input / SDL (D-pad or stick = move, A = shot, B = bomb, Start, Select = BACK).
  Keyboard (Desktop Mode): arrows, Z = A, X = B, C = X, V = Y, Enter = START, Right Shift = BACK, F11 = fullscreen.
  Button remapping, screen rotation (TATE), layout, picture and sound settings are the game's own OPTIONS menus.

KNOWN ISSUES (beta 3)
  - This is the first build on an AMD GPU: if it does not start, send logs/ (the newest file).
  - Some shell/menu elements (the top-menu circles, PRESS START, the title logo) can flicker briefly. Known.
